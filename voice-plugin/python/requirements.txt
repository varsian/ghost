# torch/torchaudio must come from the CUDA 12.8 wheel index: the RTX 5060 Laptop is

# this curated set, because its own dependency list pulls the WebUI and fine-tuning
# stack (gradio, datasets, spaces, funasr, modelscope) that inference does not need —
# and the funasr/transformers pins conflict with the model runtime.
#
#   uv venv <TTS_RUNTIME_ROOT>\.venv-vox --python 3.12
#   uv pip install --python "…\.venv-vox\Scripts\python.exe" \
#       torch torchaudio --index-url https://download.pytorch.org/whl/cu128
#   uv pip install --python "…\.venv-vox\Scripts\python.exe" voxcpm==1.5.0 --no-deps
#   uv pip install --python "…\.venv-vox\Scripts\python.exe" -r requirements.txt
#
# (a venv created by uv has no `pip` module; use `uv pip` or `python -m ensurepip` first)
#
# The denoiser (ZipEnhancer) is deliberately not installed: it needs a ModelScope
# download and caps voice cloning at 16 kHz, while VoxCPM 1.5 decodes at 44.1 kHz.
#

# runtime needs no speech-recognition stack.
